## 21:30 2026-09-01 — seventeen resolved BUGS.md entries retire

Bookkeeping pass: seventeen entries closed across four fix rounds move out of
`BUGS.md` into this file, read against the commit that closed each rather than
against what the entry hoped for.

**TC-105 — delete-property fired on objects V8 never made fast.** `delete` on
an `Object.create(null)` receiver was reported as a demotion; V8 builds that
object from `slow_object_with_null_prototype_map`, already in dictionary mode,
so the cost `bench/delete.jl` prices never happens there. mathjs `lruQueue`
built two such maps and hit three of its ten errors this way. The guard now
reads the receiver's initializer — `Object.create(null)` is typed `any`, so
only the initializer separates the two objects — and stays silent on a
`const`/`let` or class-field receiver built that way. Fixed in `573391f`.

**TC-106 — closed-world walked into abstract stubs and reported the throw as
an unchecked hot call.** yjs's `AbstractContent` conforms structurally, so the
walk resolved a call to its stub and reported the `throw` inside it as hot —
nine such warnings, on code that runs only if the program is broken, while the
one nine-implementation hierarchy in the corpus produced no dispatch finding
at all. A method whose whole body is one `throw` is now a declaration, not an
implementation: `followable` refuses it and `isDispatchDecl` reads it as a
dispatch site, so one implementation is followed and five report
megamorphic-dispatch as they should. Fixed in `bb9ebbf`.

**TC-109 — closed-world said "no body" while printing the file and line of
two bodies.** pixi's `arrayUploadFunction` reached two readable local
functions; the walk located both, printed their positions, and then said "we
have no body for" and offered to inline a callee it had just found. `Dispatch`
now carries `located` — how many origins the walk found a readable body for,
distinct from how many reach the receiver — and the "no body" sentence is
reserved for `located === 0`. Above zero the finding names the located bodies
and says the walk did not pick between them; following them stays a walk
change, recorded and not made. Fixed in `8b7c96c`.

**TC-108 — a platform call through a computed key was reported as unchecked
user code.** `gl.texParameteri(...)` counted as the platform; `gl[name](...)`
on the next line did not, because `getSymbolAtLocation` answers nothing for an
element access, so the callee resolved to no declaration and the fix line
asked the reader to inline a native WebGL method. Ten of those in pixi.
`targetsOf` now falls back to the receiver type's property when the key's type
is a literal, the same declaration a property access resolves to; a key typed
`string` names no one property and is left alone. Fixed in `e1d2a22`.

**TC-31 — a call through a parameter was neither followed nor reported.**

**TC-80 — second half: an unresolved bare import could not tell a missing
