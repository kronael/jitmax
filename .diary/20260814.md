## 15:54 2026-08-14

Three detection extensions landed. `accumulating-spread` gained `acc.concat(v)`

## 15:58 2026-08-14

Strings are refuted, and the refutation caught a live false positive. Matching
`.concat()` by name indicted `s = s.concat(x)`, which measures 0.27-0.54x of
the push-and-join rewrite — the "defect" beats its own fix. The receiver's type
now decides, and an unknown receiver stays silent.

## 16:02 2026-08-14

`Object.keys(o).map(f)` measured 0.94x — the chain is faster than the fused
loop — so the rule fires on `entries` and not on `keys`. The gap is exactly the
two-element array `entries` allocates per key.
