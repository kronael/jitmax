# 2026-08-15

## 03:30 2026-08-15

Wrote the project CLAUDE.md, which did not exist. It carries the layout and the
one thing a reader cannot guess: there are two evidences per rule, and how to
verify each. The V8 half needs a sparse checkout at the pinned revision, so the
clone commands are written out rather than implied.

## 03:34 2026-08-15

TC-11 is signed off and running: a repetition floor of five, and a per-cell
region extension up to a cap when the floor will not fit in 120 ms. Then the 35
flagged cells get re-measured and every published range that moves gets
re-derived. The most-quoted number in the project — 2348x at n=10000 — ran at
two repetitions and is in that set.

## 04:10 2026-08-15

The floor was reverted before it ran. Five and 1000 ms are constants nobody
measured, which is the objection this project raises against every rule it
refuses. 120 ms is 120 ms however many passes fill it; the rep count is a fact
about the kernel, and it is recorded, not thresholded.

## 04:12 2026-08-15

What the audit actually found: the bootstrap resamples the pairs of ONE sweep, so
it cannot see between sweeps. Replaced by SPEC §4 rule 13 — three whole sweeps
per published cell, agreement is a value common to all three intervals.

object pays it as fully as 262144 do.
