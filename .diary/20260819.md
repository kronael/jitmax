
## 13:21 2026-08-19


**v0.7.0 — the adversarial review, incorporated.** Three hostile reviews found
ten defects in the shipped output. Nine are closed today; every one was
reproduced here before it was written down.

**TC-37, protocol rule 13 had no code path to publication.** `replicates()`
lived in `bench/driver.js` and was called only to print the word DISAGREES to a
terminal while a sweep ran. `lib/derive.ts` never called it, so a cell whose
three sweeps refute each other was withdrawn only when a human happened to
re-read the rows, and twelve were not re-read. The gate now runs where the
number is made: a citation aggregates the cells that replicate, names the ones
it withdrew in the provenance, and throws when nothing is left. Three citations
were left with nothing. `map` then `filter` fell from 6.48-7.51x to 1.44-1.52x,
which is the page's second-biggest number gone. `closed-world`'s floor stopped
being the dissenting sweep's own ratio. The withdrawn cells are still published
— as refutations, through an `unreplicable` flag that throws if the cell ever
starts agreeing.

The gate counts SWEEPS, not the `protocol: 'replicated'` marker. Reading the
marker let 46 dispatch cells through: each had one plain sweep and two
replicated ones, which is three sweeps of that cell under one runner.

**TC-42, the flagship rule could not detect what its own benchmark measured.**
`bench/shapes.js` varies key ORDER — five maps, and one TypeScript type, because
key order is not part of a type. The rule counted union MEMBERS. So it was
silent on the exact program its number came from, and fired on five aliases of
one type, which `%HaveSameMap` reports as one map. It now counts distinct
property-name sets, which no rename can change, and `bench/shape-sets.js`
measures the shapes the rule can actually see.

**Seven smaller ones.** `allocating-select` read a return TYPE as an
allocation and now requires the callee body to build something.
`chained-allocation` matched method names and fired on strings.
`delete-property` fired on array elements, which go holey rather than
dictionary-mode, and whose printed fix boxed the array. `accumulating-spread`
was evaded by a property target or a `forEach`, and its object fix line stopped
being an instruction: it states both measured halves and ends with the sentence
the exit code cannot say — *the mutating form checks CLEAN*. `closed-world`
prints `bound` rather than `measured`, because its trigger and its benchmark are
different programs. The `silent` clause split in two: a refutation and a
deliberate miss are not the same claim. The page inherits every honesty
condition README carries.

**What the machine cost.** Two cores, and the load gate is `nproc - 1`. The
dispatch sweep took 1h28m for 92 rows; the shape-sets sweep spent most of an
hour waiting for the machine to fall below the gate rather than measuring
anyway. That is the protocol working, and it is also why TC-41's k-axis sweep is
disclosed rather than run.

**The sweep landed, and the rule keeps its number.** `bench/shape-sets.js`, 24
cells, three whole sweeps each, 53m36s, no void cells. Five distinct property
sets against one, reads only: 10.78/11.35/11.00 at L1, 9.09/8.96/8.51 at L2,
4.04/4.12/3.37 at RAM size — all three replicate. Two to four sets read
0.95-1.47x. So the threshold really is at the fifth, and it is not an artefact
of key order.

`megamorphic-elements` now cites `3.4-11.3x` from a sweep of the shapes it can
detect. The key-order sweep is not deleted and not demoted: it measures
`4.4-11.5x` for a cost nothing static can find, which is exactly what the new
`unreported` clause is for.
