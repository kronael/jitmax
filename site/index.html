jitmax

A static checker for speed-sensitive TypeScript on V8 — numba's @njit, for V8

TL;DR
Mark a hot TypeScript function with /** @jitmax */. jitmax checks it and every function it calls whose source it can read, and reports the patterns that measurably push V8 off its fast path: a fifth object shape at one property read or method call, a delete, an array built per pipeline stage. You get findings with file and line, the next step, and an exit code a CI gate can read. Slowdown rules cite their benchmark; coverage rules report unchecked calls without claiming they are slow. It never runs or rewrites your code. Run it from your project root: bunx github:kronael/jitmax src

Try it

You need Bun and TypeScript 5.x or 6.x in the project you check. bun add typescript installs 7.x, which lacks the compiler API jitmax uses, so a project without TypeScript, or on 7.x, adds 6.x with bun add --dev typescript@^6. Save this as shapes.ts in the project root. The element type declares five property sets: 

type Row =
  | { kind: 'a'; x: number }
  | { kind: 'b'; x: number; y: number }
  | { kind: 'c'; x: number; z: number }
  | { kind: 'd'; x: number; w: number }
  | { kind: 'e'; x: number; v: number };

/** @jitmax */
export function total(rows: Row[]): number {
  let sum = 0;
  for (const row of rows) sum += row.x;
  return sum;
}
bunx github:kronael/jitmax shapes.ts

It exits 1, and its finding reads:

The first line is the annotated function the walk started from; the finding can sit in any function it calls. next: is what to try, and note: what that change can break besides speed. On the benchmark behind this rule, reads through five property sets ran 3.4–11.3x slower than through one. A finding is a measured candidate, not a cost in your program: most input sizes are only known at runtime, and a printed fix can make the call slower. Benchmark your caller before you keep a change. Bun runs the checker; every rule is about V8, not Bun's engine.

Now install your project's dependencies, mark your own hot function and run bunx github:kronael/jitmax src. --help lists every argument.
