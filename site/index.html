jitmax

Check speed-sensitive TypeScript for V8 slowdowns

Mark a function /** @jitmax */. jitmax checks that function and the functions it calls for patterns that benchmarks show can slow V8. V8 is the JavaScript engine in Node, Chrome and Deno. You get source locations, next steps and calls the checker could not follow.

What it checks

jitmax reports mixed object shapes at property reads and method calls, property deletion, repeated copying and avoidable allocations. Each slowdown rule cites its benchmark. Coverage rules report unchecked calls without claiming those calls are slow. See the rules and their limits.

jitmax reads source without running or rewriting your code. A clean run does not guarantee V8 optimization or fast execution. The measurements come from one machine. A suggested change can make your caller slower. Profile and benchmark your workload before keeping a change. See the measured library fixes.
